# Hiroshima TCT Wiki

広島大学における **TCT (Transient Current Technique) scan** 測定のための Wiki です。
シリコン検出器の評価に TCT を用いる学生・研究者が、原理の理解から測定・解析までを一通り行えることを目指しています。
