# 用語集

TCT
:   Transient Current Technique。レーザーで生成した電荷による過渡電流を測定する手法。

DUT
:   Device Under Test。被測定デバイス（センサー）。

空乏層 (depletion region)
:   自由キャリアがなく、電場がかかっている領域。ここで生成された電荷が信号に寄与する。

全空乏化電圧 (full depletion voltage, \(V_\text{fd}\))
:   センサーの厚さ全体が空乏化する電圧。

重み電場 (weighting field)
:   注目する電極を 1 V、他の電極を 0 V にしたときの電場。Shockley–Ramo の定理で誘起電流を求めるのに使う。

CCE
:   Charge Collection Efficiency。電荷収集効率。

LGAD
:   Low Gain Avalanche Detector。内部に増幅層を持ち、10〜数十倍程度の利得を持つシリコンセンサー。

PIN ダイオード
:   増幅層を持たない基本的なダイオード構造のセンサー。LGAD のゲイン評価の基準に使う。

MIP
:   Minimum Ionizing Particle。最小電離粒子。

フルエンス (fluence)
:   単位面積あたりに照射された粒子数。1 MeV 中性子等価 (n<sub>eq</sub>/cm²) で表すことが多い。

トラッピング (trapping)
:   放射線損傷による欠陥準位にキャリアが捕獲されること。

Edge-TCT
:   センサーの側面からレーザーを入射して深さ方向を走査する TCT。

TPA-TCT
:   Two-Photon Absorption TCT。2 光子吸収を用いて 3 次元の分解能を得る TCT。

CFD
:   Constant Fraction Discrimination。振幅の一定割合で時刻を決める方法。

バイアスティー (bias tee)
:   直流バイアスと高周波信号を分離・合成する素子。
