# 用語集

TCT
:   Transient Current Technique。レーザーで生成した電荷による過渡電流を測定する手法。

DUT
:   Device Under Test。被測定デバイス（センサー）。

空乏層 (depletion region)
:   自由キャリアがなく、電場がかかっている領域。ここで生成された電荷が信号に寄与する。

全空乏化電圧 (full depletion voltage, \(V_\text{fd}\))
:   センサーの厚さ全体が空乏化する電圧。

重み電場 (weighting field)
:   注目する電極を 1 V、他の電極を 0 V にしたときの電場。Shockley–Ramo の定理で誘起電流を求めるのに使う。

CCE
:   Charge Collection Efficiency。電荷収集効率。

LGAD
:   Low Gain Avalanche Detector。内部に増幅層を持ち、10〜数十倍程度の利得を持つシリコンセンサー。

PIN ダイオード
:   増幅層を持たない基本的なダイオード構造のセンサー。LGAD のゲイン評価の基準に使う。

MIP
:   Minimum Ionizing Particle。最小電離粒子。

フルエンス (fluence)
:   単位面積あたりに照射された粒子数。1 MeV 中性子等価 (n<sub>eq</sub>/cm²) で表すことが多い。

トラッピング (trapping)
:   放射線損傷による欠陥準位にキャリアが捕獲されること。

Edge-TCT
:   センサーの側面からレーザーを入射して深さ方向を走査する TCT。

TPA-TCT
:   Two-Photon Absorption TCT。2 光子吸収を用いて 3 次元の分解能を得る TCT。

CFD
:   Constant Fraction Discrimination。振幅の一定割合で時刻を決める方法。

バイアスティー (bias tee)
:   直流バイアスと高周波信号を分離・合成する素子。

## 広島の装置・GUI に関する用語

AC-LGAD
:   AC-coupled LGAD。LGAD の増幅層の上に連続した n+ 抵抗層と AC 結合電極を置いた構造。信号が抵抗層を広がって複数の電極に分配されるので、電極ピッチより細かい位置分解能が得られる。

ePIC / bTOF
:   EIC（電子・イオン衝突型加速器）の ePIC 実験と、そのバレル部の飛行時間検出器。AC-LGAD ストリップを使う。

laser_gui
:   広島の TCT 装置の制御 GUI（AC-LGAD レーザースキャン制御 GUI）。オシロ・ステージ・レーザー・カメラを 1 つのウィンドウで操作する。

TUNE
:   PiLAS レーザーのパルスの強さを決める設定値 [%]。0 % が最強、100 % が最弱。最適値は繰り返し周波数で変わる。

TRIG OUT
:   レーザーコントローラのトリガー出力。オシロの外部トリガー (EXT) に入れ、時刻の基準にする。

論理座標 / 論理原点
:   GUI が使うセンサー基準の座標 [µm]。原点は X = 外枠 (GND) エッジ、Y = 基準 CH の電極中心、Z = 焦点。

機械座標 / 機械原点
:   ステージコントローラの機械原点 (H:W) を基準にした座標。GUI が R:W を跨いで追跡する。

H:W / R:W / M:W / L:W
:   SHRC-203 のコマンド。H:W は機械原点復帰、R:W は論理原点リセット（現在位置を 0 にする）、M:W は相対移動、L:W は停止。

M-ORG
:   ジョイスティック JS-301 からの機械原点復帰。GUI の機械座標の追跡が切れるので、GUI の H:W を使う。

原点出し
:   レーザー信号を物差しにして、焦点・電極中心・外枠エッジを自動で求め、論理原点を決める処理。

フル較正
:   原点出しに加えて、センサーの傾き係数 dY/dX、dZ/dX、dZ/dY を実測する処理。

シーケンスモード / セグメント
:   オシロが 1 回のトリガーごとの波形（セグメント）を多数まとめて取得するモード。1 点あたり 2000 セグメントが標準。

PAVA / PKPK
:   LeCroy の波形パラメータ。GUI は振幅の読み取りに使う（PKPK はピーク・ツー・ピーク）。

TRIGTIME
:   LeCroy のシーケンス波形で、各セグメントのトリガー時刻。到達時刻の原点に使う。

VICP
:   LeCroy 独自の LAN 制御プロトコル（ポート 1861）。

MIP 相当
:   レーザーの波高を、ビームテストで測った MIP の信号量（DESY ビームテストのストリップ中間で隣接 2ch 合計 64 mV など）に合わせた状態。
