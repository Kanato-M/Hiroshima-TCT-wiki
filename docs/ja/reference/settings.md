# 標準設定値一覧

測定の標準条件と GUI の既定値の一覧です。値の出典は `config.py`（2026-07 実測で確定した標準条件）と GUI のソースコードです。

## センサー・バイアス

| 項目 | 値 | 備考 |
| --- | --- | --- |
| HV（センサーバイアス） | 190–195 V（センサー温度 33 °C のとき）。温度によって変える | Matsusada P4L650-0.1、手動。GUI のステータスバーの参考値は −185 V |
| LV（読み出しボード） | 6.0 V | Rohde & Schwarz NGP800 シリーズ、手動 |
| 投入順 | 他の機器の電源の後、LV → HV | 他の機器の電源は順不同 |
| 読み出し | C1=J8、C2=J7、C3=J6、C4=J5 | 標準センサー |

## レーザー

| 項目 | 値 | 備考 |
| --- | --- | --- |
| トリガーソース | internal (ts=0) | レーザーが基準クロック |
| 繰り返し周波数 | **1 MHz** | 変更可能。GUI の初期値は 1.25 MHz なので注意 |
| TUNE | manual **50 %** | 1 MHz で MIP 相当に調整済み（2026-10）。0 % が最強、100 % が最弱 |
| カメラ用照明 | 測定中は OFF | 暗室内で手動操作 |
| TUNE 最適化：単一 CH の目標 | 200 mV（PKPK） | |
| TUNE 最適化：隣接 2ch 合計の目標 | 64 mV | DESY ビームテスト (2026) のストリップ中間の MIP 相当値 |
| TUNE 最適化：許容誤差 / 粗掃引 step | ±1 mV / 2 % | 精密掃引は 0.5 % 刻み |
