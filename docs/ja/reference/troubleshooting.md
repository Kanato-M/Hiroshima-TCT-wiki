# トラブルシューティング

まず GUI 左下の **通信ログ**（`logs/gui_YYYYMMDD.log`）を見て、どのコマンドで何が返ってきたかを確認してください。

## 接続できない { #connection }

| 症状 | 対処 |
| --- | --- |
| オシロ：接続できない、「接続中」なのに設定が反映されない | リソース名を `VICP::192.168.0.2::INSTR` にする。オシロ本体の Utilities → Utilities Setup → Remote で、制御方式（TCPIP (VICP) または LXI (VXI11)）と IP を確かめる。ping が通れば VICP で接続できるはず。接続時に `*IDN?` の応答を検証し、応答がなければ VICP ⇔ VXI-11 を自動で試した上でエラーになる |
| ステージ：ping は通るのに接続がタイムアウトする | TCP ポート番号が本体の設定と違う。実機は **9004**。接続先の欄に `192.168.0.3:<ポート>` と入れる。前のセッションが接続を占有しているときは、コントローラを再起動する。接続できても無応答なら、SHOT 互換モード・デリミタ (CRLF) を確認する |
| レーザー：接続できない | デバイスマネージャで COM 番号を確認する（制御 PC は COM5）。FTDI VCP ドライバが入っているか確認する |
| カメラ：映らない | [デバイス] 番号を変えてみる（既定 0） |

## 信号が出ない・おかしい { #no-signal }

| 症状 | 考えられる原因 | 対処 |
| --- | --- | --- |
| 信号がまったく出ない | レーザーが発振していない | レーザーパネルの状態表示が赤帯の「発振: ON」か確認する |
| | ビームが電極（金属）の上にある | ジョグで Y を数十 µm ずらしてシリコン上に置く |
| | バイアスがかかっていない | LV 6.0 V、HV（33 °C で −190〜−195 V）。LV は OUTPUT が青色に点灯しているか、HV は赤ボタンでバイアス ON になっているかを確認する |
| | 水平オフセットが違う | [★ 標準設定を一括適用 ★] で −53 ns にする |
| 波形は更新されるのに平坦 | 周波数を変えて TUNE が発振閾値を下回った（TRIG OUT は出続ける） | [TUNE 最適化](../measurement/tune.md) をやり直す。簡易確認なら TUNE を auto にする |
| 振幅が想定と違う | カメラ用照明が ON のまま、周波数が 1 MHz でない、アライメントがずれている | 照明を OFF、1 MHz・TUNE 50 % を確認。それでも違えば TUNE 最適化で合わせる |
| スキャンで電極の上の信号が 0 まで落ちない、電極端の立ち上がりがなだらか | デフォーカス、または座標のずれ | 原点出し（Z の確認）をやり直す |

## ステージ・位置合わせ

| 症状 | 対処 |
| --- | --- |
| 「機械座標: 不明」と出て、登録原点へ移動できない | GUI が機械座標を追跡できていない（JS-301 から M-ORG した、コントローラを再起動した、原点復帰を途中で止めた等）。GUI から [機械原点復帰 (H:W)] を実行する |
| 原点出しが「明確なディップがありません」「明確なエッジがありません」で止まる | ビームが基準ストリップ上で端から 50〜200 µm 内側にあるか、レーザーが ON か、信号が見えているかを確かめて再実行する |
| 「谷が浅すぎます」・Z の谷を特定できない | Z 範囲を ±30〜50 µm に広げる、カメラで粗くフォーカスを合わせてから再実行する |
| フル較正の Z 残差が数 µm を超える、係数が前回から大きく変わった | 再実行するか、スキャンの Z 追従を「実測 Z」方式にする |
| 原点出し・フル較正の後に右カラムが横に広がる、傾き係数の表示が古い | 旧版の不具合（2026-10 改修で修正済み）。最新版を使う |
| ジョグの向きがカメラ画像と合わない | カメラやステージの取り付け向きを変えた。`config_local.json` の `stage_screen_dir` を直す |

## スキャン

| 症状 | 対処 |
| --- | --- |
| 「保存ファイルが増えていません」で中断した | オシロ側のファイル数が 2 点続けて増えないと、自動で止まる。オシロの Save Waveform 設定と保存先フォルダを確かめる |
| スキャンログに `timeout` が並ぶ | 時間内に取得が終わっていない。レーザーが ON か、EXT トリガーが掛かっているかを確かめる。[アベレージング OFF] のチェックを外していないかも見る |
| 開始時に「Z が 30 µm 以上離れている」警告 | 意図どおりか確認する。原点出しをしていない・Z 追従の方式が違う可能性がある |

## データ回収

| 症状 | 対処 |
| --- | --- |
| SSH 接続に失敗する | オシロが起動していて ping が通るか、オシロ側の OpenSSH サーバが動いているか、パスワードが正しいかを確かめる |
| 「競合」が報告された | PC 側に同名でサイズが違うファイルがある。上書きはされないので、どちらが正しいか確認して手動で整理する |
| スキャン中に転送できない | 仕様（排他）。スキャン終了後に転送する |

## カメラ

| 症状 | 対処 |
| --- | --- |
| 画像が真っ暗、または真っ白 | カメラパネルの [ゲイン] を調整する（効いたかは通信ログの実値で確認できる。実値が変わらなければカメラ側が非対応）。直らなければ、照明の明るさとレンズの絞りを調整する |

## 一般的な TCT のトラブル

??? note "他の TCT 装置にも共通するトラブル"

    | 症状 | 考えられる原因 | 確認・対処 |
    | --- | --- | --- |
    | 波形が振動する（リンギング） | インピーダンス不整合、配線が長い | 50 Ω 終端、ケーブル・ワイヤーボンドを短くする |
    | 波形が飽和・クリップする | アンプやオシロの入力レンジ超過 | 縦軸レンジを広げる、レーザー強度を下げる |
    | 強度を変えると波形の形が変わる | 生成電荷が多すぎる（プラズマ効果） | レーザー強度を下げる |
    | ノイズが大きい | グラウンドループ、外来ノイズ | グラウンドを 1 点にまとめる、シールドを確認する |
    | 信号が時間とともにドリフトする | レーザー強度・温度の変動 | 基準点を定期的に測り直す |
    | リーク電流が急増する | ブレークダウン | ただちに電圧を下げる |
