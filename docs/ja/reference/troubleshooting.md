# トラブルシューティング

| 症状 | 考えられる原因 | 確認・対処 |
| --- | --- | --- |
| 信号がまったく出ない | レーザーが発振していない、シャッターが閉じている | レーザーの状態、インターロック、ファイバーの接続を確認する |
| | ビームが金属電極の上に当たっている | XY スキャンで光学窓やストリップ間を探す |
| | バイアスがかかっていない | 電源出力、バイアスティー、ケーブルを確認する |
| | トリガー設定が違う | トリガー源・レベル・時間軸の位置を確認する |
| 信号が小さい | 焦点が合っていない | フォーカススキャンをやり直す |
| | 空乏化が不十分 | バイアスを上げる（リーク電流に注意） |
| 波形が振動する（リンギング） | インピーダンス不整合、配線が長い | 50 Ω 終端、ケーブル・ワイヤーボンドを短くする |
| 波形が飽和・クリップする | アンプやオシロの入力レンジ超過 | 縦軸レンジを広げる、レーザー強度を下げる |
| 強度を変えると波形の形が変わる | 生成電荷が多すぎる（プラズマ効果） | レーザー強度を下げる |
| ノイズが大きい | グラウンドループ、外来ノイズ | グラウンドを 1 点にまとめる、シールドを確認する |
| 信号が時間とともにドリフトする | レーザー強度・温度の変動 | 基準点を定期的に測り直す、温度が安定するまで待つ |
| リーク電流が急増する | ブレークダウン、結露 | ただちに電圧を下げる、露点を確認する |
| 電源がコンプライアンスで止まる | 制限値が小さすぎる、センサーの損傷 | IV 測定で状態を確認し、制限値を見直す |
| 冷却中に結露した | パージ不足 | 電圧を下げ、乾燥してから室温に戻す |

!!! note "追記のお願い"
    実際に遭遇したトラブルと解決方法を、ぜひこの表に追記してください。
