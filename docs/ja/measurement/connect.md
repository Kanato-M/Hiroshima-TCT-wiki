# 1. 起動と機器の接続

GUI を起動し、機器を接続して、レーザー信号がオシロに見える状態にするまでの手順です。
ここまで終われば、次の [位置合わせ](alignment.md) に進めます。

!!! note "前提"
    機器の電源が入り、LV 6.0 V と HV −185 V がかかっていること（[測定の全体の流れ](procedure.md#power-on)）。

## 1-1. GUI を起動する

GUI のフォルダで起動します（[制御 PC とソフトウェア](../setup/software.md)）。

```bat
python main.py
```

## 1-2. 機器を接続する

| パネル | 操作 | 確認すること |
| --- | --- | --- |
| オシロスコープ | VISA 欄が `VICP::192.168.0.2::INSTR` であることを確認して [接続] | 「接続中」と表示される |
| 3 軸ステージ | 接続先が `192.168.0.3:9004` であることを確認して [接続] | 「接続中」、座標が表示される |
| レーザー | ポートが `COM5` であることを確認して [接続] | 「接続中」、状態表示（Interlock、Trig、Freq、Tune、Head）が出る |
| フォーカスカメラ | [開始] | 画像が映る |

- 接続すると、ボタンは [切断] に変わります。
- レーザーパネルの入力欄（トリガーソース、繰り返し周波数、TUNE）は、接続時に **実機の現在値へ同期** されます。
- ステージは接続時に移動速度（`stage_speed_pps`）が全軸へ設定されます。

接続できないときは [トラブルシューティング](../reference/troubleshooting.md#connection) を見てください。

## 1-3. 機械原点復帰 (H:W)

SHRC-203 は起動直後に **機械原点復帰** が必要です。

1. **サンプル（読み出しボード）と対物レンズが干渉しないことを確かめる。** 全軸が大きく動きます。
2. ステージパネル [操作] タブの **[機械原点復帰 (H:W)]** を押す。
3. 完了すると、機械座標の追跡が始まります（[機械座標](../setup/sensor.md#machine)）。

!!! warning "GUI から実行する"
    ジョイスティック JS-301 の M-ORG でも原点復帰はできますが、**GUI から実行したときだけ** 機械座標の追跡が始まります。
    追跡できていないと「機械座標: 不明」と表示され、登録原点への移動ができません。

## 1-4. センサーを選ぶ

ツールバーの [センサー] で測定する DUT を選びます。切り替えると、スキャンの既定範囲、傾き係数、登録位置、
オシロ CH と読み出しパッドの対応が、そのセンサーのものに入れ替わります。

- 通常は「標準ストリップ (500 µm ピッチ, 10 mm)」です。
- 初めての DUT は [編集...] から登録します（[新しい DUT を登録する](../setup/sensor.md#new-sensor)）。

## 1-5. 粗寄せする { #coarse }

原点出しを始める位置へ、ビームを大まかに寄せます。目標は **基準ストリップ（標準は C1）の上で、露出部の読み出し側端から 50〜200 µm 内側** です（±100 µm 程度の精度で十分）。

![ステージパネルの [位置登録] タブ](../images/gui/stage-position-tab.png){ width="480" }

### 原点が登録されている場合（通常）

[位置登録] タブの **[原点出し開始位置へ]** を押します。前回登録した原点（機械座標）をもとに、
基準ストリップ上で露出部の読み出し側端から 100 µm 内側の位置へ移動します。

- [登録原点へ移動] は、前回の論理原点（外枠エッジ上）へ移動します。
- どちらも機械座標を使うので、1-3 の H:W を GUI から実行していることが前提です。

### センサーを載せ替えた直後・原点が未登録の場合

カメラの **十字線** を目安に、[操作] タブのジョグで同じ位置へ寄せます。

1. カメラパネルで [十字線] にチェックを入れる。画像が暗すぎる・明るすぎるときは [ゲイン] を調整する。
2. ジョグの [ステップ] を大きめ（500 µm〜1 mm）にして、基準ストリップの読み出し側端の近くまで動かす。
3. ステップを小さくして（10〜50 µm）、露出部の読み出し側端から 50〜200 µm 内側に十字線を合わせる。
4. Z ジョグでカメラ画像のピントを大まかに合わせる。

!!! tip "ジョグの向き"
    矢印は **カメラ画像の上で動く向き** です。ボタンの文字は実際に送る軸と符号で、▲ は Y− です。

!!! question "要確認"
    カメラ用照明の ON/OFF の方法と、測定中は OFF にすべきか（照明の ON/OFF で TUNE と信号振幅の関係が変わるため）。

### [位置登録] タブのその他の機能

| 機能 | 内容 |
| --- | --- |
| [ストリップへ移動] | CH と場所（読み出し側端 / 中央 / 反対側端）を選ぶと、センサー形状と傾き係数から座標を計算して移動する。**行き先は電極の中心線上で、そこでは信号が出ない** ので、TUNE 最適化や Z フォーカスの前には Y を数十 µm ずらしてシリコン上に置く |
| [現在位置を登録] | 現在位置に名前を付けて登録する。[論理座標で登録] した位置は原点出しをやり直してもセンサー上の同じ場所を指す。[機械座標で登録] した位置は原点を出す前の粗寄せに使う |
| [選択位置へ移動] / ダブルクリック | 登録位置へ移動する |
| [現在の論理原点を登録] | 現在の論理原点の機械座標をセンサーに登録する（原点出しでは自動で登録される） |

## 1-6. レーザーを発振させる

レーザーパネルで次を設定し、それぞれの **[設定]** を押して送信します。

| 項目 | 設定 |
| --- | --- |
| トリガーソース | internal (ts=0)（レーザーが基準クロック） |
| 繰り返し周波数 | 下の要確認 |
| TUNE | 後で [TUNE 最適化](tune.md) で合わせる。ここでは信号が見える値でよい |

!!! danger "発振させる前に"
    暗室（暗箱）が閉じていて、中に人がいないことを確認してください。1064 nm の光は目に見えません（[安全上の注意](../introduction/safety.md)）。

設定したら **[発振 ON (ld=1)]** を押し、確認ダイアログでインターロック・光学系を確認してから [Yes] を押します。
状態表示が赤帯の「発振: ON」になります。

!!! question "要確認"
    標準の繰り返し周波数。解析ノート matome の主なスキャンは 40 MHz（一部 1 MHz）、GUI の初期値は 1.25 MHz（TCT 推奨）です。

!!! warning "周波数を変えたら TUNE を合わせ直す"
    最適な TUNE は繰り返し周波数で変わります。ある周波数で合わせた manual の TUNE のまま周波数を変えると、発振閾値を下回って
    光が出なくなることがあります。このとき TRIG OUT は出続けるので、オシロの波形は更新されるのに平坦なままになります。
    周波数を変えたら [TUNE 最適化](tune.md) をやり直してください。

## 1-7. オシロを標準設定にする

1. オシロパネルの **[ミラー開始]** で本体の画面を GUI に表示する。
2. [トリガー/掃引] タブの **[★ 標準設定を一括適用 ★]** を押す。

標準設定の内容：

| 項目 | 値 |
| --- | --- |
| トリガー | EXT、DC、POS、410 mV |
| 横軸 | 1 ns/div、水平オフセット **−53 ns**（表示範囲 +48〜+58 ns） |
| 縦軸（C1〜C4） | 50 mV/div、オフセット +100 mV（表示範囲 −300〜+100 mV） |
| 入力結合 | DC 50 Ω（D50） |
| アベレージング | OFF |

個別に変えるときは [トリガー/掃引] タブと [チャンネル] タブを使います。

??? info "水平オフセットが −53 ns である理由"
    AC-LGAD の信号は、レーザートリガーの約 52 ns 後に来ます（1 MHz で実測）。以前の設定 −4 ns で信号が見えていたのは、
    40 MHz（周期 25 ns）では 2 周期後のトリガーから見た同じ信号が 52 − 50 = +2 ns に折り返していたためです。
    −53 ns にしておけば、繰り返し周波数に関係なく同じ窓（+48〜+58 ns）に信号が入ります。
    この値は `config.py` の `scope_trig_delay` で決まります。

!!! warning "アベレージングは OFF で使う"
    ON のままだと、シーケンスや SINGLE 取得の完了判定が働かず、スキャンが timeout になります。

## 1-8. 信号を確認する

オシロのミラー画面で、C1〜C4 のどれかに信号が見えることを確認します。

- ビームが **電極（金属）の上** にあると信号は出ません。[原点出し開始位置へ] の行き先は基準ストリップの電極の上なので、
  そこでは信号がほとんど出ません。信号を確かめるときは、ジョグで Y を数十 µm ずらしてストリップ横のシリコン上に置きます
  （確認したら元の位置へ戻してから原点出しを始めます。±100 µm 程度のずれは許容されます）。
- 信号が見えない場合は [トラブルシューティング](../reference/troubleshooting.md#no-signal) を見てください。

信号が見えたら、[2. 位置合わせ](alignment.md) に進みます。
