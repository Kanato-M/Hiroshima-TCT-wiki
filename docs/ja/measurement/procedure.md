# 測定手順

以下は一般的な TCT 測定の流れです。研究室の装置固有の手順があれば追記してください。

!!! danger
    作業前に [安全上の注意](../introduction/safety.md) を読んでください。

## 1. 準備

- [ ] センサー ID・種類・照射履歴（フルエンス、アニーリング）を記録する
- [ ] センサーを基板に実装し、信号線・バイアス線・グラウンドの接続を確認する
- [ ] 顕微鏡でセンサー表面に傷や汚れがないか確認する
- [ ] 測定ログに日付・目的・測定者を記入する

## 2. 環境の立ち上げ

- [ ] センサーを暗箱内のステージに固定し、暗箱を閉める
- [ ] 乾燥空気（または窒素）のパージを開始する
- [ ] 冷却する場合は、**露点が十分低くなってから** 冷却を始める
- [ ] 温度・湿度が安定するまで待つ

## 3. IV 確認（レーザー OFF）

- [ ] 高圧電源のコンプライアンスを設定する
- [ ] レーザー OFF の状態でバイアスをゆっくり上げ、リーク電流を確認する
- [ ] 想定外に大きなリーク電流や急激な増加（ブレークダウン）がないことを確認する

## 4. レーザーの調整

- [ ] インターロックが有効であることを確認し、レーザーを発振させる
- [ ] 低めの強度から始め、オシロスコープで信号を確認する
- [ ] オシロスコープのトリガーをレーザーのトリガー出力に設定する

## 5. 位置合わせ

- [ ] 粗い XY スキャンでセンサーの位置（電極端、光学窓）を探す
- [ ] [フォーカススキャン](scans.md#focus-scan) で焦点位置 \(z\) を決める
- [ ] 測定したい位置にビームを合わせる

## 6. 本測定

- [ ] 目的に応じたスキャン（[スキャンの種類](scans.md)）を実行する
- [ ] 適宜、同じ条件の基準点を測り直して、レーザー強度のドリフトを確認する
- [ ] 波形を目で見て、飽和・リンギング・ノイズがないか確認する

## 7. 終了

- [ ] レーザーを停止する
- [ ] バイアスを段階的に 0 V まで下げ、出力を OFF にする
- [ ] 冷却していた場合は **室温に戻るまで待ってから** 暗箱を開ける
- [ ] データのバックアップをとり、測定ログを完成させる

## 測定条件の記録項目

| 項目 | 例 |
| --- | --- |
| センサー | ID、種類、厚さ、照射フルエンス |
| 環境 | 温度、湿度（露点） |
| バイアス | 電圧、リーク電流 |
| レーザー | 波長、強度設定、繰り返し周波数、照射面 |
| 読み出し | アンプ、ケーブル、オシロスコープ設定（レンジ、平均回数） |
| スキャン | 種類、範囲、ステップ |
