# 信号形成

## 電子・正孔対の生成とドリフト

レーザー光が半導体に吸収されると電子・正孔対が生成されます。
バイアス電圧で空乏化した領域では、電子と正孔はそれぞれ逆向きにドリフトし、電極に到達するまでの間、電極に電流を誘起します。

ドリフト速度は電場 \(E\) と移動度 \(\mu\) で決まります。

\[
\vec{v}_{e,h} = \pm \mu_{e,h}(E)\,\vec{E}
\]

移動度は電場が高くなると下がり、シリコン中のドリフト速度は高電場で飽和します
（室温で電子・正孔ともおよそ \(10^7\) cm/s のオーダー）。

## Shockley–Ramo の定理

電極に誘起される電流は **Shockley–Ramo の定理** で与えられます。
電荷 \(q\) が速度 \(\vec{v}\) で位置 \(\vec{r}\) を動くとき、注目する電極の誘起電流は

\[
I(t) = q\,\vec{v}(t)\cdot\vec{E}_w\big(\vec{r}(t)\big)
\]

です。ここで \(\vec{E}_w\) は **重み電場 (weighting field)** で、
注目する電極を 1 V、他のすべての電極を 0 V にし、空間電荷を取り除いたときの電場です。

厚さ \(d\) の平行平板（パッドダイオード）では \(E_w = 1/d\) なので、

\[
I(t) = \frac{q}{d}\,\big(v_e(t) + v_h(t)\big)
\]

となります。電流波形には **ドリフト速度、すなわち電場分布の情報** が含まれています。

!!! tip "セグメント化された電極"
    ストリップやピクセルでは重み電場が電極付近に集中するため、
    電極近くを動く電荷ほど大きな信号を誘起します。
    隣接電極には両極性の誘起電流（クロストーク様の信号）が現れることがあります。

## 収集電荷

収集電荷は誘起電流の時間積分です。

\[
Q = \int I(t)\,dt
\]

実際の測定では、オシロスコープで 50 Ω 終端された電圧 \(V(t)\) を記録するため、アンプの利得 \(G\) を考慮して

\[
Q = \frac{1}{G\,R}\int V(t)\,dt, \qquad R = 50\ \Omega
\]

で換算します。
\(G\) の値はアンプの仕様書または校正測定から求めてください。

## 赤色レーザーによる片側注入と波形の形

赤色レーザー（例：波長 660 nm 付近）は表面から数 µm 以内で吸収されるため、電荷はほぼ表面だけで生成されます。

- 生成直後に片方のキャリアはすぐ近くの電極に吸収される。
- もう片方のキャリアだけがセンサーの厚さ全体をドリフトする。

このため、照射する面を選ぶことで **電子だけ** または **正孔だけ** の信号を観測できます。
平行平板では \(I(t) \propto v(E(x(t)))\) なので、波形は電場の深さ分布を時間軸に写したものになります。

!!! example "例：p⁺–n–n⁺ ダイオード"
    p⁺ 側から赤色レーザーを当てると、正孔はすぐ p⁺ 電極に吸収され、電子が n⁺ 側へドリフトします（電子信号）。
    n⁺ 側から当てると、正孔が p⁺ 側へドリフトします（正孔信号）。
    空乏化した n 型バルクでは電場が p⁺ 側で最大、n⁺ 側に向かって線形に減少するため、
    電子信号は時間とともに減少し、正孔信号は時間とともに増加する形になります。

## 放射線損傷とトラッピング

放射線照射で生じた欠陥準位はキャリアを捕獲（トラップ）し、信号を減少させます。
有効トラッピング時間を \(\tau_\text{eff}\) とすると、ドリフト中のキャリア数は

\[
N(t) = N_0\,\exp\!\left(-\frac{t}{\tau_\text{eff}}\right)
\]

で減少し、誘起電流も同じ因子で小さくなります。
\(\tau_\text{eff}\) はフルエンスにほぼ反比例して短くなります。

また、照射後のセンサーでは空間電荷の分布が変わり、
電場が両方の電極付近で高くなる **ダブルピーク** 構造が現れることがあります。
