# スキャンの種類（一般論）

!!! info "このページは一般論です"
    TCT で一般に行われるスキャンの紹介です。広島の装置（AC-LGAD + laser_gui）で実際に行うスキャンは
    [自動スキャン](../measurement/scans.md) を見てください。
    特に **焦点の決め方が一般論と逆** になる点に注意してください。広島の AC-LGAD では、焦点が合うほど
    ゲインが抑制されて振幅が **小さく** なるので、「振幅最小の Z = 焦点」とします
    （[位置合わせ](../measurement/alignment.md#focus) 参照）。

## フォーカススキャン { #focus-scan }

ビームの焦点（ビームウェスト）の位置を決めるためのスキャンです。

1. 金属電極の端（ナイフエッジ）をまたぐように \(x\) 方向にスキャンする。
2. 信号（振幅または電荷）を位置の関数として誤差関数でフィットする。

    \[
    S(x) = \frac{A}{2}\left[1 + \operatorname{erf}\!\left(\frac{x - x_0}{\sqrt{2}\,\sigma}\right)\right] + C
    \]

3. これを光軸方向 \(z\) の各位置で繰り返し、\(\sigma\) が最小になる \(z\) を焦点とする。

ビーム幅は \(\text{FWHM} = 2\sqrt{2\ln 2}\,\sigma \approx 2.355\,\sigma\) で表すこともあります。

!!! tip
    Edge-TCT では、センサーの表面・裏面（深さ方向の端）を使って同様に焦点サイズを評価できます。

## 位置スキャン（XY スキャン）

照射位置を 1 次元または 2 次元に走査して、応答の位置依存性を調べます。

- ストリップ間・ピクセル間の電荷共有
- LGAD のゲイン層の一様性、パッド間の不感領域 (inter-pad distance)
- 電極端・ガードリング付近の挙動

!!! note
    金属電極の上はレーザーが透過しないため、信号がゼロになります。
    マップを解釈するときはレイアウト図と重ねて確認してください。

## バイアススキャン

バイアス電圧を変えながら同じ位置で波形を取得します。

- **収集電荷 vs バイアス**：電荷が飽和する電圧から全空乏化電圧を推定する。
- **波形の形 vs バイアス**：電場分布の変化を確認する。
- **LGAD のゲイン**：同じ条件で測った PIN ダイオードとの電荷比 \(G = Q_\text{LGAD} / Q_\text{PIN}\) から求める。

!!! warning
    電圧を上げるときはリーク電流を常に監視し、ブレークダウンの兆候があれば中止してください。

## Edge-TCT 深さスキャン

センサーの側面からレーザーを入射し、深さ \(y\) を走査します。複数のバイアスで繰り返すのが一般的です。

- 各深さの **収集電荷** → 電荷収集プロファイル（空乏層の広がり）
- 各深さの **立ち上がり直後の電流** → ドリフト速度プロファイル（電場分布）

詳しくは [レーザーと照射方式](../principle/lasers.md#edge-tct) を参照してください。

## 温度スキャン

温度を変えながら測定します。リーク電流、トラッピング、LGAD のゲイン（温度が低いほど高くなる）などの温度依存性を調べます。
温度を変えたら、安定するまで十分待ってから測定してください。

## レーザー強度スキャン

レーザー強度を変え、信号が強度に比例しているか（線形性）を確認します。
強度が高すぎるとプラズマ効果やアンプの飽和で波形が歪むため、本測定の前に一度行っておくと安心です。
