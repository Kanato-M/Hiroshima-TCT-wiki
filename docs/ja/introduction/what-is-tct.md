# TCT とは

**TCT (Transient Current Technique)** は、半導体検出器の中に短パルスのレーザーで電子・正孔対を生成し、
それらが電場中をドリフトすることで電極に誘起される **過渡電流 (transient current)** を
高速アンプとオシロスコープで時間分解して測定する手法です。

## 何がわかるか

TCT の波形からは、次のような検出器の性質を調べることができます。

| 評価項目 | 内容 |
| --- | --- |
| 収集電荷 | 電流波形の積分から、生成された電荷のうち電極に収集された量を求める |
| 全空乏化電圧 | バイアス電圧に対する収集電荷の飽和点から推定する |
| 電場分布・ドリフト速度 | 波形の形状（特に Edge-TCT の立ち上がり直後の電流）から推定する |
| 有効トラッピング時間 | 放射線損傷を受けたセンサーの電荷の目減りから推定する |
| 内部増幅率 (ゲイン) | LGAD などの増幅層付きセンサーと PIN ダイオードの信号比から求める |
| 位置依存性 | レーザーを走査し、ピクセル間・ストリップ間・電極端の応答を調べる |
| 時間特性 | 立ち上がり時間、タイミングジッターなど |

## 粒子ビーム・線源試験との違い

- **長所**
    - レーザーの位置・タイミング・強度を自由に制御できるため、µm スケールでの位置スキャンができる。
    - 線源やビームより手軽で、多数の波形を平均して低ノイズのデータを得られる。
    - 照射する波長を変えることで、表面付近だけ、あるいはバルク全体に電荷を生成できる。
- **短所・注意点**
    - 生成電荷量の絶対値はレーザー強度に依存し、強度のふらつきが系統誤差になる。
    - 荷電粒子とはエネルギー付与の揺らぎ（Landau 揺らぎ）が異なるため、
      レーザーで得たタイミング分解能は MIP（最小電離粒子）での分解能と同じではない。
    - 金属電極はレーザーを通さないため、照射できる位置が限られる。

## TCT の主な種類

| 方式 | 概要 |
| --- | --- |
| Top-TCT (front/back) | センサー表面（または裏面）に垂直にレーザーを当てる基本的な方式 |
| Edge-TCT | 研磨した側面からレーザーを入射し、深さ方向に走査する |
| TPA-TCT | 2 光子吸収を用いて焦点付近のみで電荷を生成し、3 次元の分解能を得る |

詳しくは [レーザーと照射方式](../principle/lasers.md) を参照してください。
